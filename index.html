Unit 1 · Number

Lesson 1: The Real Number System

Learning goal: classify numbers and understand how the main number sets are related.

1. Natural and whole numbers

Natural numbers are counting numbers: 1, 2, 3, 4, … . In this course, we use whole numbers to include zero: 0, 1, 2, 3, … .

2. Integers

Integers include negative whole numbers, zero and positive whole numbers.

…, −3, −2, −1, 0, 1, 2, 3, …

3. Rational numbers

A rational number can be written as a fraction a/b, where a and b are integers and b ≠ 0. Its decimal form terminates or repeats.

Examples: 3/4 = 0.75; 1/3 = 0.333…; −5 = −5/1.

4. Irrational numbers

An irrational number cannot be written as a ratio of two integers. Its decimal expansion neither terminates nor repeats.

Examples: √2, π. Note: √9 = 3, so √9 is rational, not irrational.

5. Real numbers

The real numbers include all rational and irrational numbers. Every point on the number line represents a real number.

Rational numbers ∪ Irrational numbers = Real numbers

Worked example

Classify −2.75.

  1. Write it as a fraction: −2.75 = −275/100 = −11/4.
  2. It is a ratio of integers, so it is rational.
  3. All rational numbers are real numbers.

Answer: −2.75 is rational and real.

Common mistake

Not every square root is irrational. Simplify the radicand first: √16 = 4 is rational, while √5 is irrational.

Unit 1 · Number

Lesson 2: Understanding Radicals

Learning goal: evaluate square roots, identify perfect squares and simplify simple radicals.

1. What is a square root?

The square root of a non-negative number n is the non-negative number that, when multiplied by itself, gives n.

√49 = 7 because 7 × 7 = 49

Remember: √49 means the principal (positive) square root. The equation x² = 49 has two solutions: x = 7 or x = −7.

2. Perfect squares

Useful perfect squares include:

1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144

3. Simplifying a radical

Look for the largest perfect-square factor inside the radical.

Example: Simplify √72.
  1. 72 = 36 × 2.
  2. √72 = √36 × √2.
  3. √72 = 6√2.

4. Estimating a square root

Since 25 < 30 < 36, it follows that 5 < √30 < 6.

Unit 2 · Exponents

Lesson 3: Exponent Laws

Learning goal: simplify powers with the same base and apply zero and negative exponents.

Product law

aᵐ × aⁿ = aᵐ⁺ⁿ

Example: 2³ × 2⁴ = 2⁷ = 128.

Quotient law

aᵐ ÷ aⁿ = aᵐ⁻ⁿ   (a ≠ 0)

Example: x⁷ ÷ x³ = x⁴.

Power of a power

(aᵐ)ⁿ = aᵐⁿ

Example: (x³)² = x⁶.

Zero exponent

a⁰ = 1   (a ≠ 0)

Negative exponent

a⁻ⁿ = 1/aⁿ   (a ≠ 0)

Example: 2⁻³ = 1/2³ = 1/8.

Worked example:
(2x³)² × x⁴ ÷ x²
= 4x⁶ × x⁴ ÷ x²
= 4x⁸.
